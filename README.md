# Проект 1. Риск инсульта

Учебный проект по машинному обучению (Модуль 1, Часть Б). Поликлиника хочет по модели отбирать пациентов на бесплатное углублённое обследование: пропустить пациента с высоким риском опаснее, чем лишний раз обследовать здорового.

## Что внутри

| Файл | Описание |
|---|---|
| `stroke_risk_project.ipynb` | основной ноутбук: блоки A (базовый), B (основной), C (продвинутый) с кодом, графиками и выводами |
| `healthcare-dataset-stroke-data.csv` | данные: 5110 пациентов, целевая переменная `stroke` |
| `requirements.txt` | нужные библиотеки |

## Как запустить

```bash
pip install -r requirements.txt
jupyter notebook stroke_risk_project.ipynb
```

Дальше в Jupyter: *Run → Run All Cells*. CSV должен лежать в одной папке с ноутбуком.

## Кратко о результатах

- **Блок A:** при пороге 0.5 точность 95%, но модель находит 1 больного из 50. Accuracy при редком классе обманывает.
- **Блок B:** Pipeline без утечек, две модели (LogReg, RandomForest), `StratifiedKFold(5)`, метрика F2, подбор порога по кросс-валидации. На тесте найдено 36 из 50 больных (recall 72%), на обследование отправлено 17,6% пациентов.
- **Блок C:** список проблем и утечек (с экспериментом по утечке при oversampling), сравнение class_weight / oversampling / undersampling / порога, анализ ошибок по группам, ограничения. Модель в основном опирается на возраст и плохо находит молодых больных.

Фиксированный `random_state=42` делает результаты воспроизводимыми.
